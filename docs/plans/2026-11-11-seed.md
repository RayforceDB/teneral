# Teneral Seed Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the seed of teneral: a small fixed kernel that runs, gates, promotes and rolls back generations of a minimal agent, and an agent that is woken by sensors, can edit its own code and ask the kernel to molt onto it.

**Architecture:** Two halves in one repo. `kernel/` is a supervisor the agent may never change: it owns the append-only journal, runs the agent as a child process from a `live` git worktree, and when the agent exits with code 75 it runs gates on the `candidate` worktree, promotes the new commit, and rolls back if that generation fails to come up. `body/` is everything the agent may rewrite: a provider call, six tools, sensors that turn the outside world into journal stimuli (terminal, clock, and a file inbox other agents write to), and a turn loop that journals an intent before every tool call. The conversation lives in `memory/journal.jsonl` and outlives every generation; each event is stamped with the commit that produced it.

**Tech Stack:** TypeScript on Bun (`bun test`, `Bun.spawn`), git worktrees, JSONL. No runtime dependencies. Dev dependencies: `typescript`, `@types/bun`. Any OpenAI-compatible chat-completions endpoint.

**How a molt works**

1. The agent edits files in `.teneral/candidate` (branch `lineage/local`). Its running code is in `.teneral/live` and is never edited.
2. The agent calls the `molt` tool. The tool commits the candidate, journals `molt.requested`, and the process exits with code 75 when the turn ends.
3. The supervisor runs the gates on the candidate. On failure it journals `molt.rejected` and restarts the same generation.
4. On success it checks the commit out into `live`, journals `generation.promoted`, and starts it.
5. If the new generation exits abnormally before journaling `generation.ready`, or crashes three times without producing a reply, the supervisor checks out the previous commit and journals `generation.rolledback`.
6. On its next start the agent sees the kernel's note in its context and continues the conversation.

**Not in this plan (deliberately)**

- The probe set (fixed tasks replayed against every generation). It is the next plan; until it exists, "better" is not measured, only "not broken".
- Memory compression. Context is truncated from the front. Fixing that is the agent's own backlog.
- Sensors beyond terminal, clock and inbox; bridges to chat services; any UI.
- Signed messages and kernel-enforced trust between agents. The seed only tells the agent, in its prompt, not to act on another agent's request.
- MCP. A minimal client is a later backlog item for the agent itself.
- Exchanging mutations with upstream `main`.
- Privilege separation between kernel and body. The container (Task 16) protects the machine from the agent; it does not stop the body from editing the kernel's files directly. That needs the body to run as a different user, and is the next plan.

```ts
import { randomUUID } from 'node:crypto';
import {
  closeSync, existsSync, fstatSync, fsyncSync, mkdirSync, openSync, readFileSync, readSync, writeSync,
} from 'node:fs';
import { dirname } from 'node:path';

/** Bump only with a reader that still understands every older version. */
export const SCHEMA_VERSION = 1;

export interface ToolCall {
  id: string;
  name: string;
  args: unknown;
}

export type EventBody =
  | { type: 'stimulus'; source: string; text: string }
  | { type: 'assistant'; text: string; toolCalls: ToolCall[] }
  | { type: 'tool.intent'; callId: string; name: string; args: unknown }
  | { type: 'tool.result'; callId: string; ok: boolean; output: string }
  | { type: 'molt.requested'; commit: string; motive: string }
  | { type: 'molt.rejected'; commit: string; gate: string; output: string }
  | { type: 'generation.started'; commit: string }
  | { type: 'generation.ready'; commit: string }
  | { type: 'generation.promoted'; commit: string; previous: string }
  | { type: 'generation.rolledback'; commit: string; to: string; reason: string };

/** `gen` is the commit of the code that wrote the event. */
export type JournalEvent = EventBody & { v: number; id: string; ts: string; gen: string };

function endsWithNewline(fd: number): boolean {
  const size = fstatSync(fd).size;
  if (size === 0) return true;
  const last = Buffer.alloc(1);
  readSync(fd, last, 0, 1, size - 1);
  return last[0] === 0x0a;
}

export function appendEvent(path: string, gen: string, body: EventBody): JournalEvent {
  const event = {
    v: SCHEMA_VERSION, id: randomUUID(), ts: new Date().toISOString(), gen, ...body,
  } as JournalEvent;
  mkdirSync(dirname(path), { recursive: true });
  const fd = openSync(path, 'a+');
  try {
    // A crash can leave half a line behind; start on a fresh one so only that line is lost.
    const prefix = endsWithNewline(fd) ? '' : '\n';
    writeSync(fd, `${prefix}${JSON.stringify(event)}\n`);
    fsyncSync(fd);
  } finally {
    closeSync(fd);
  }
  return event;
}

export function readEvents(path: string): JournalEvent[] {
  if (!existsSync(path)) return [];
  const events: JournalEvent[] = [];
  for (const line of readFileSync(path, 'utf8').split('\n')) {
    if (line === '') continue;
    try {
      events.push(JSON.parse(line) as JournalEvent);
    } catch {
      // A torn line from a crash mid-write. Nothing after it depends on it.
    }
  }
  return events;
}
```

```ts
const IDENTITY = ['-c', 'user.name=test', '-c', 'user.email=test@localhost'];

export function writeFiles(dir: string, files: Record<string, string>): void {
  for (const [path, content] of Object.entries(files)) {
    mkdirSync(dirname(join(dir, path)), { recursive: true });
    writeFileSync(join(dir, path), content);
  }
}

/** Stage everything, commit, return the new commit. */
export function commitAll(dir: string, message: string): string {
  git(dir, 'add', '-A');
  git(dir, ...IDENTITY, 'commit', '-q', '-m', message);
  return git(dir, 'rev-parse', 'HEAD');
}

/** A fresh repo on `main` with one commit holding `files`. */

  writeFiles(dir, { '.gitignore': 'node_modules\nsoul\nmemory\ninbox\n.teneral\n', ...files });
```

```ts
import { statSync } from 'node:fs';
import { join } from 'node:path';
import { protectedChanges } from './protected';

/** Bytes of tracked files under body/. Roughly 50k tokens: small enough to read whole. */
export const BODY_SIZE_LIMIT = 200_000;

export interface GateResult {
  ok: boolean;
  gate: string;
  output: string;
}

export interface Check {
  gate: string;
  cmd: string[];
}

export const DEFAULT_CHECKS: readonly Check[] = [
  { gate: 'types', cmd: ['bun', 'x', 'tsc', '--noEmit'] },
  { gate: 'tests', cmd: ['bun', 'test'] },
];

export function sh(cmd: string[], cwd: string, timeoutMs = 600_000): { code: number; output: string } {
  const p = Bun.spawnSync(cmd, { cwd, stdout: 'pipe', stderr: 'pipe', timeout: timeoutMs });
  return { code: p.exitCode ?? 1, output: p.stdout.toString() + p.stderr.toString() };
}

/** Runs git in `dir`; throws with git's own words when it fails. */
export function git(dir: string, ...args: string[]): string {
  const r = sh(['git', ...args], dir);
  if (r.code !== 0) throw new Error(`git ${args.join(' ')} failed: ${r.output.trim()}`);
  return r.output.trim();
}

export function bodySize(dir: string): number {
  return git(dir, 'ls-files', '-z', 'body')
    .split('\0')
    .filter(Boolean)
    .reduce((total, file) => total + statSync(join(dir, file)).size, 0);
}

/**
 * Decide whether commit `to`, checked out in `dir`, may replace generation `from`.
 * Checks run inside `dir`, so they test the candidate's code, not the running one.
 */
export function runGates(dir: string, from: string, to: string, checks: readonly Check[] = DEFAULT_CHECKS): GateResult {
  const fail = (gate: string, output: string): GateResult => ({ ok: false, gate, output: output.slice(-4000) });
  try {
    if (git(dir, 'rev-parse', 'HEAD') !== to) return fail('head', `the candidate is not at ${to}`);
    if (git(dir, 'status', '--porcelain') !== '') return fail('head', 'the candidate has uncommitted changes');
    // --no-renames lists both ends of a move, so moving a protected file out is caught.
    // -z: without it git prints unusual names quoted and escaped, which would not match the allowlist.
    const changed = git(dir, 'diff', '--name-only', '--no-renames', '-z', from, to).split('\0').filter(Boolean);
    const forbidden = protectedChanges(changed);
    if (forbidden.length > 0) return fail('protected', `protected paths changed: ${forbidden.join(', ')}`);
    const size = bodySize(dir);
    if (size > BODY_SIZE_LIMIT) return fail('size', `body/ is ${size} bytes; the limit is ${BODY_SIZE_LIMIT}`);
  } catch (err) {
    return fail('git', err instanceof Error ? err.message : String(err));
  }
  for (const check of checks) {
    const r = sh(check.cmd, dir);
    if (r.code !== 0) return fail(check.gate, r.output);
  }
  return { ok: true, gate: 'all', output: '' };
}
```

```ts
/** The agent exits with this code to ask for a molt. */
export const MOLT_EXIT = 75;
/** Crashes in a row, with no reply in between, before a generation is given up on. */
export const CRASH_LIMIT = 3;

export interface Exit {
  code: number;
  /** The generation journaled `generation.ready` during this run. */
  ready: boolean;
}

export type Decision = 'stop' | 'gate' | 'restart' | 'rollback' | 'halt';

/** `crashes` counts earlier crashes of this generation since its last reply. */
export function decide(exit: Exit, s: { hasPrevious: boolean; crashes: number }): Decision {
  if (exit.code === 0) return 'stop';
  if (exit.code === MOLT_EXIT) return 'gate';
  const givenUp = !exit.ready || s.crashes + 1 >= CRASH_LIMIT;
  if (!givenUp) return 'restart';
  return s.hasPrevious ? 'rollback' : 'halt';
}
```

```ts
/** The branch the agent's own commits live on. Never pushed by the kernel. */
export const LINEAGE_BRANCH = 'lineage/local';

export interface Paths {
  root: string;
  /** Worktree the running agent's code is checked out in. */
  live: string;
  /** Worktree the agent edits. */
  candidate: string;
  journal: string;
  state: string;
}

export function paths(root: string): Paths {
  return {
    root,
    live: join(root, '.teneral', 'live'),
    candidate: join(root, '.teneral', 'candidate'),
    journal: join(root, 'memory', 'journal.jsonl'),
    state: join(root, '.teneral', 'state.json'),
  };
}

export interface State {
  current: string;
  /** The generation to return to if `current` fails; null when there is none. */
  previous: string | null;
}

function saveState(p: Paths, state: State): void {
  mkdirSync(join(p.root, '.teneral'), { recursive: true });
  const tmp = `${p.state}.tmp`;
  writeFileSync(tmp, `${JSON.stringify(state, null, 2)}\n`);
  renameSync(tmp, p.state);
}

function linkModules(root: string, dir: string): void {
  const source = join(root, 'node_modules');
  const target = join(dir, 'node_modules');
  if (existsSync(source) && !existsSync(target)) symlinkSync(source, target);
}

/** First run: create both worktrees at HEAD. Later runs: read the state back. */
export function init(root: string): State {
  const p = paths(root);
  if (existsSync(p.state)) return JSON.parse(readFileSync(p.state, 'utf8')) as State;
  const head = git(root, 'rev-parse', 'HEAD');
  mkdirSync(join(root, '.teneral'), { recursive: true });
  git(root, 'worktree', 'add', '--detach', p.live, head);
  git(root, 'worktree', 'add', '-b', LINEAGE_BRANCH, p.candidate, head);
  linkModules(root, p.live);
  linkModules(root, p.candidate);
  const state: State = { current: head, previous: null };
  saveState(p, state);
  return state;
}

export interface Options {
  root: string;
  agentCmd?: string[];
  gates?: (dir: string, from: string, to: string) => GateResult;
  /** How long a generation has to journal `generation.ready` before it is killed. */
  readyTimeoutMs?: number;
  log?: (line: string) => void;
}

function lastOf<T extends JournalEvent['type']>(events: JournalEvent[], type: T): Extract<JournalEvent, { type: T }> | undefined {
  for (let i = events.length - 1; i >= 0; i--) {
    const e = events[i]!;
    if (e.type === type) return e as Extract<JournalEvent, { type: T }>;
  }
  return undefined;
}

/** Run generations until the agent exits cleanly ('stopped') or nothing can run ('halted'). */
export async function supervise(opts: Options): Promise<'stopped' | 'halted'> {
  const p = paths(opts.root);
  const gates = opts.gates ?? runGates;
  const cmd = opts.agentCmd ?? ['bun', 'body/main.ts'];
  const readyTimeoutMs = opts.readyTimeoutMs ?? 30_000;
  const log = opts.log ?? ((line: string) => console.error(`[teneral] ${line}`));
  let state = init(opts.root);
  let crashes = 0;
  let stopping = false;
  let child: ReturnType<typeof Bun.spawn> | null = null;
  const onSignal = () => { stopping = true; child?.kill(); };
  process.on('SIGINT', onSignal);
  process.on('SIGTERM', onSignal);

  try {
    for (;;) {
      const mark = readEvents(p.journal).length;
      appendEvent(p.journal, state.current, { type: 'generation.started', commit: state.current });
      const since = () => readEvents(p.journal).slice(mark);
      const isReady = () => since().some((e) => e.type === 'generation.ready' && e.gen === state.current);

      child = Bun.spawn(cmd, {
        cwd: p.live,
        env: { ...process.env, TENERAL_GEN: state.current, TENERAL_JOURNAL: p.journal, TENERAL_WORKSPACE: p.candidate },
        stdin: 'inherit', stdout: 'inherit', stderr: 'inherit',
      });
      const running = child;
      const timer = setTimeout(() => { if (!isReady()) running.kill(); }, readyTimeoutMs);
      const code = await running.exited;
      clearTimeout(timer);
      child = null;
      if (stopping) return 'stopped';

      const events = since();
      const replied = events.some((e) => e.type === 'assistant');
      if (replied) crashes = 0;
      const decision = decide({ code, ready: isReady() }, { hasPrevious: state.previous !== null, crashes });

      if (decision === 'stop') return 'stopped';
      if (decision === 'halt') {
        log(`generation ${state.current} exited with ${code} and there is nothing to roll back to`);
        return 'halted';
      }
      if (decision === 'restart') {
        crashes += 1;
        log(`generation ${state.current} exited with ${code}; restarting (${crashes}/${CRASH_LIMIT})`);
        continue;
      }
      if (decision === 'rollback') {
        const to = state.previous!;
        const reason = isReady() ? `crashed ${CRASH_LIMIT} times without a reply` : `exited with ${code} before it was ready`;
        git(p.live, 'checkout', '-q', '--detach', to);
        appendEvent(p.journal, to, { type: 'generation.rolledback', commit: state.current, to, reason });
        log(`rolled back ${state.current} to ${to}: ${reason}`);
        state = { current: to, previous: null };
        saveState(p, state);
        crashes = 0;
        continue;
      }
      // decision === 'gate'
      const request = lastOf(events, 'molt.requested');
      if (!request) {
        log('the agent exited with 75 but named no commit; restarting');
        continue;
      }
      const result = gates(p.candidate, state.current, request.commit);
      if (!result.ok) {
        appendEvent(p.journal, state.current, { type: 'molt.rejected', commit: request.commit, gate: result.gate, output: result.output });
        log(`molt to ${request.commit} rejected at gate ${result.gate}`);
        continue;
      }
      git(p.live, 'checkout', '-q', '--detach', request.commit);
      appendEvent(p.journal, request.commit, { type: 'generation.promoted', commit: request.commit, previous: state.current });
      log(`promoted ${request.commit}`);
      state = { current: request.commit, previous: state.current };
      saveState(p, state);
      crashes = 0;
    }
  } finally {
    process.off('SIGINT', onSignal);
    process.off('SIGTERM', onSignal);
  }
}
```

```ts
import type { ToolCall } from '../kernel/journal';

export interface WireToolCall {
  id: string;
  type: 'function';
  function: { name: string; arguments: string };
}

export interface ChatMessage {
  role: 'system' | 'user' | 'assistant' | 'tool';
  content: string | null;
  tool_calls?: WireToolCall[];
  tool_call_id?: string;
}

export interface ToolSpec {
  name: string;
  description: string;
  parameters: Record<string, unknown>;
}

export interface Reply {
  text: string;
  toolCalls: ToolCall[];
}

export type Provider = (messages: ChatMessage[], tools: ToolSpec[]) => Promise<Reply>;

export interface ProviderConfig {
  baseUrl: string;
  apiKey: string;
  model: string;
  fetch?: typeof fetch;
}

function parseArgs(raw: string): unknown {
  try {
    return JSON.parse(raw);
  } catch {
    return raw;
  }
}

export function openAiProvider(cfg: ProviderConfig): Provider {
  const send = cfg.fetch ?? fetch;
  const url = `${cfg.baseUrl.replace(/\/+$/, '')}/chat/completions`;
  return async (messages, tools) => {
    const body: Record<string, unknown> = { model: cfg.model, messages };
    if (tools.length > 0) body.tools = tools.map((t) => ({ type: 'function', function: t }));
    const res = await send(url, {
      method: 'POST',
      headers: { 'content-type': 'application/json', authorization: `Bearer ${cfg.apiKey}` },
      body: JSON.stringify(body),
    });
    const text = await res.text();
    if (!res.ok) throw new Error(`provider answered ${res.status}: ${text.slice(0, 2000)}`);
    const message = (JSON.parse(text) as { choices?: { message?: { content?: string | null; tool_calls?: WireToolCall[] } }[] })
      .choices?.[0]?.message;
    if (!message) throw new Error(`provider reply has no message: ${text.slice(0, 2000)}`);
    return {
      text: message.content ?? '',
      toolCalls: (message.tool_calls ?? []).map((c) => ({ id: c.id, name: c.function.name, args: parseArgs(c.function.arguments) })),
    };
  };
}
```

```ts
import { mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, resolve } from 'node:path';
import { git } from '../kernel/gates';
import { appendEvent } from '../kernel/journal';
import type { ToolSpec } from './provider';

export interface ToolContext {
  /** The candidate worktree: the only copy of the code the agent edits. */
  workspace: string;
  journal: string;
  gen: string;
  /** Set by `molt`; the process exits with 75 once the turn ends. */
  moltCommit: string | null;
}

export interface Tool {
  spec: ToolSpec;
  run(args: unknown, ctx: ToolContext): Promise<string>;
}

const OUTPUT_CAP = 20_000;

export function cap(text: string): string {
  if (text.length <= OUTPUT_CAP) return text;
  return `${text.slice(0, OUTPUT_CAP)}\n[cut: ${text.length - OUTPUT_CAP} more characters]`;
}

function str(args: unknown, key: string): string {
  const value = typeof args === 'object' && args !== null ? (args as Record<string, unknown>)[key] : undefined;
  if (typeof value !== 'string') throw new Error(`missing string argument: ${key}`);
  return value;
}

function params(properties: Record<string, string>): Record<string, unknown> {
  return {
    type: 'object',
    properties: Object.fromEntries(Object.entries(properties).map(([k, description]) => [k, { type: 'string', description }])),
    required: Object.keys(properties),
  };
}

const read: Tool = {
  spec: { name: 'read', description: 'Read a file. Paths are relative to your workspace.', parameters: params({ path: 'File path' }) },
  async run(args, ctx) {
    return cap(readFileSync(resolve(ctx.workspace, str(args, 'path')), 'utf8'));
  },
};

const write: Tool = {
  spec: {
    name: 'write',
    description: 'Create or overwrite a file, creating parent directories.',
    parameters: params({ path: 'File path', content: 'Full file content' }),
  },
  async run(args, ctx) {
    const path = resolve(ctx.workspace, str(args, 'path'));
    const content = str(args, 'content');
    mkdirSync(dirname(path), { recursive: true });
    writeFileSync(path, content);
    return `wrote ${content.length} characters to ${str(args, 'path')}`;
  },
};

const edit: Tool = {
  spec: {
    name: 'edit',
    description: 'Replace one exact occurrence of `old` with `new` in a file. Fails unless `old` occurs exactly once.',
```

```ts
import type { JournalEvent } from '../kernel/journal';
import type { ChatMessage } from './provider';

const INTERRUPTED =
  '[interrupted] The process stopped while this tool was running. It may have partly run. Check the current state before repeating it.';
const NOT_STARTED = '[not started] The process stopped before this tool ran. It is safe to call it again.';

/** What the kernel did, in words the agent reads; null for events that are not news. */
export function kernelNote(e: JournalEvent): string | null {
  switch (e.type) {
    case 'molt.rejected':
      return `[kernel] Your molt to ${e.commit} was rejected at gate "${e.gate}". You are still running generation ${e.gen}.\n${e.output}`;
    case 'generation.promoted':
      return `[kernel] Your molt was accepted. You are now running generation ${e.commit} (before: ${e.previous}).`;
    case 'generation.rolledback':
      return `[kernel] Generation ${e.commit} ${e.reason} and was rolled back. You are running ${e.to} again. Your workspace still holds the code that failed.`;
    default:
      return null;
  }
}

function size(m: ChatMessage): number {
  return (m.content?.length ?? 0) + (m.tool_calls ? JSON.stringify(m.tool_calls).length : 0);
}

/** Drop from the front until the rest fits, never leaving a tool result without its call. */
function fit(messages: ChatMessage[], budgetChars: number): ChatMessage[] {
  let total = messages.reduce((sum, m) => sum + size(m), 0);
  let start = 0;
  while (start < messages.length - 1 && (total > budgetChars || messages[start]!.role === 'tool')) {
    total -= size(messages[start]!);
    start += 1;
  }
  return messages.slice(start);
}

export function buildMessages(events: JournalEvent[], system: string, budgetChars = 400_000): ChatMessage[] {
  const results = new Map<string, string>();
  const started = new Set<string>();
  for (const e of events) {
    if (e.type === 'tool.result') results.set(e.callId, e.output);
    if (e.type === 'tool.intent') started.add(e.callId);
  }

  const out: ChatMessage[] = [];
  for (const e of events) {
    if (e.type === 'stimulus') {
      out.push({ role: 'user', content: e.source === 'terminal' ? e.text : `[${e.source}] ${e.text}` });
    } else if (e.type === 'assistant') {
      if (e.toolCalls.length === 0) {
        out.push({ role: 'assistant', content: e.text });
        continue;
      }
      out.push({
        role: 'assistant',
        content: e.text === '' ? null : e.text,
        tool_calls: e.toolCalls.map((c) => ({ id: c.id, type: 'function' as const, function: { name: c.name, arguments: JSON.stringify(c.args ?? {}) } })),
      });
      // Results are placed here, right after their call, whatever was journaled in between.
      for (const c of e.toolCalls) {
        out.push({ role: 'tool', tool_call_id: c.id, content: results.get(c.id) ?? (started.has(c.id) ? INTERRUPTED : NOT_STARTED) });
      }
    } else {
      const note = kernelNote(e);
      if (note !== null) out.push({ role: 'user', content: note });
    }
  }
  return [{ role: 'system', content: system }, ...fit(out, budgetChars)];
}

/** True when the last thing in the conversation is not the agent's own finished reply. */
export function needsTurn(events: JournalEvent[]): boolean {
  let afterReply = false;
  for (const e of events) {
    if (e.type === 'assistant') afterReply = e.toolCalls.length > 0;
    else if (e.type === 'stimulus' || kernelNote(e) !== null) afterReply = true;
  }
  return afterReply;
}
```

```ts
import { appendEvent, readEvents } from '../kernel/journal';
import { buildMessages } from './context';
import type { Provider } from './provider';
import type { Tool, ToolContext } from './tools';

export interface TurnDeps {
  journal: string;
  gen: string;
  provider: Provider;
  tools: Tool[];
  system: string;
  ctx: ToolContext;
  onText?: (text: string) => void;
  maxRounds?: number;
}

/** Model, tools, model, ... until a reply with no tool calls. 'molt' means: exit with 75 now. */
export async function runTurn(d: TurnDeps): Promise<'done' | 'molt'> {
  const specs = d.tools.map((t) => t.spec);
  for (let round = 0; round < (d.maxRounds ?? 50); round++) {
    // Re-read every round: a sensor may have journaled a stimulus while a tool ran.
    const reply = await d.provider(buildMessages(readEvents(d.journal), d.system), specs);
    appendEvent(d.journal, d.gen, { type: 'assistant', text: reply.text, toolCalls: reply.toolCalls });
    if (reply.text !== '') d.onText?.(reply.text);
    if (reply.toolCalls.length === 0) return 'done';

    for (const call of reply.toolCalls) {
      // The intent goes to disk first, so a crash mid-tool is told apart from one before it.
      appendEvent(d.journal, d.gen, { type: 'tool.intent', callId: call.id, name: call.name, args: call.args });
      let ok = true;
      let output: string;
      try {
        const tool = d.tools.find((t) => t.spec.name === call.name);
        if (!tool) throw new Error(`unknown tool: ${call.name}`);
        output = await tool.run(call.args, d.ctx);
      } catch (err) {
        ok = false;
        output = `error: ${err instanceof Error ? err.message : String(err)}`;
      }
      appendEvent(d.journal, d.gen, { type: 'tool.result', callId: call.id, ok, output });
    }
    if (d.ctx.moltCommit !== null) return 'molt';
  }
  appendEvent(d.journal, d.gen, { type: 'assistant', text: '[round limit reached; waiting for the next stimulus]', toolCalls: [] });
  return 'done';
}
```

```ts
export interface Stimulus {
  /** Which sensor produced it. 'terminal' is shown to the model as plain user text. */
  source: string;
  text: string;
}

/** Start sensing; call `emit` for each stimulus; return a function that stops it. */
export type Sensor = (emit: (s: Stimulus) => void) => () => void;

/** Lines typed by the person at the terminal. `/quit` ends the agent; the end of input does not. */
export function terminal(lines: AsyncIterable<string>, onQuit: () => void): Sensor {
  return (emit) => {
    let stopped = false;
    void (async () => {
      for await (const line of lines) {
        if (stopped) return;
        const text = line.trim();
        if (text === '/quit') return onQuit();
        if (text !== '') emit({ source: 'terminal', text });
      }
    })();
    return () => { stopped = true; };
  };
}

/** A tick every `intervalMs`, so the agent gets time of its own. 0 turns it off. */
export function clock(intervalMs: number): Sensor {
  return (emit) => {
    if (intervalMs <= 0) return () => {};
    const timer = setInterval(() => {
      emit({
        source: 'clock',
        text: `It is ${new Date().toISOString()}. No one is waiting for a reply. If something on your backlog is worth doing now, do it; if not, say so in one line.`,
      });
    }, intervalMs);
    return () => clearInterval(timer);
  };
}
```

### Task 12: Mailbox

How agents, and any other program, reach each other. A message is one JSON file dropped into the receiver's `inbox/`. No connection is involved, on purpose: a teneral agent restarts often, and a file waits for it where a socket would drop the message. A bridge to a chat service is just another process that drops files here.

The envelope format lives in `kernel/`, so one individual cannot change it alone: agents at different generations must keep understanding each other.

Known limits of this version, all in the backlog: `from` is not signed, so it can be forged; the hop limit stops accidental ping-pong, not a sender who omits `replyTo`; and a crash between journaling a message and archiving its file delivers it twice (the stimulus carries the message id so the agent can tell).

```ts
import { randomUUID } from 'node:crypto';
import { existsSync, mkdirSync, readdirSync, readFileSync, renameSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';

/** Bump only with a parser that still accepts every older version. */
export const ENVELOPE_VERSION = 1;
/** Replies in one exchange before a sender must stop and ask its owner. */
export const MAX_HOPS = 4;
export const MAX_TEXT = 20_000;

export interface Envelope {
  v: number;
  /** Letters, digits and dashes only: it becomes part of a file name. */
  id: string;
  /** Who says they sent it. Not signed in this version. */
  from: string;
  to: string;
  /** Id of the message this answers, or null. */
  replyTo: string | null;
  ts: string;
  /** 0 for a first message, the answered message's hops + 1 for a reply. */
  hops: number;
  text: string;
}

const ID = /^[A-Za-z0-9-]+$/;

export function parseEnvelope(raw: string): Envelope {
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch {
    throw new Error('not JSON');
  }
  if (typeof data !== 'object' || data === null) throw new Error('not an object');
  const e = data as Record<string, unknown>;
  if (e.v !== ENVELOPE_VERSION) throw new Error(`unsupported version: ${String(e.v)}`);
  if (typeof e.id !== 'string' || !ID.test(e.id)) throw new Error('id must be letters, digits and dashes');
  for (const key of ['from', 'to', 'ts']) {
    if (typeof e[key] !== 'string' || e[key] === '') throw new Error(`missing ${key}`);
  }
  if (typeof e.text !== 'string') throw new Error('missing text');
  if (e.text.length > MAX_TEXT) throw new Error(`text is longer than ${MAX_TEXT} characters`);
  if (e.replyTo !== null && (typeof e.replyTo !== 'string' || !ID.test(e.replyTo))) throw new Error('replyTo must be an id or null');
  if (typeof e.hops !== 'number' || !Number.isInteger(e.hops) || e.hops < 0) throw new Error('hops must be a non-negative integer');
  return {
    v: ENVELOPE_VERSION, id: e.id, from: e.from as string, to: e.to as string,
    replyTo: e.replyTo as string | null, ts: e.ts as string, hops: e.hops, text: e.text,
  };
}

/** Drop an envelope into an inbox. The rename makes it appear whole or not at all. */
export function deliver(inbox: string, envelope: Envelope): string {
  mkdirSync(inbox, { recursive: true });
  const file = `${Date.now()}-${envelope.id}.json`;
  const tmp = join(inbox, `.tmp-${envelope.id}`);
  writeFileSync(tmp, JSON.stringify(envelope));
  renameSync(tmp, join(inbox, file));
  return file;
}

export interface Arrival {
  file: string;
  /** null when the file is not a valid envelope; `reason` then says why. */
  envelope: Envelope | null;
  reason: string | null;
}

/** Everything waiting in an inbox, oldest first. Files stay put until `archive`. */
export function collect(inbox: string): Arrival[] {
  if (!existsSync(inbox)) return [];
  return readdirSync(inbox)
    .filter((name) => name.endsWith('.json') && !name.startsWith('.'))
    .sort()
    .map((file) => {
      try {
        return { file, envelope: parseEnvelope(readFileSync(join(inbox, file), 'utf8')), reason: null };
      } catch (err) {
        return { file, envelope: null, reason: err instanceof Error ? err.message : String(err) };
      }
    });
}

export function archive(inbox: string, file: string, where: 'seen' | 'rejected'): void {
  mkdirSync(join(inbox, where), { recursive: true });
  renameSync(join(inbox, file), join(inbox, where, file));
}

/** A message this inbox already took in, by id. */
export function findSeen(inbox: string, id: string): Envelope | null {
  const dir = join(inbox, 'seen');
  if (!existsSync(dir)) return null;
  const file = readdirSync(dir).find((name) => name.endsWith(`-${id}.json`));
  return file ? parseEnvelope(readFileSync(join(dir, file), 'utf8')) : null;
}

/** This individual's id: made on first use, kept in the directory it is given (`.teneral/`), never in git. */
export function identity(dataDir: string): string {
  const path = join(dataDir, 'id');
  if (existsSync(path)) return readFileSync(path, 'utf8').trim();
  mkdirSync(dataDir, { recursive: true });
  const id = randomUUID();
  writeFileSync(path, `${id}\n`);
  return id;
}
```

```ts
/** Messages other agents and programs dropped into this agent's inbox directory. */
export function inbox(dir: string, intervalMs = 2000): Sensor {
  return (emit) => {
    const poll = () => {
      for (const arrival of collect(dir)) {
        const e = arrival.envelope;
        if (e === null) {
          console.error(`[inbox] set aside ${arrival.file}: ${arrival.reason}`);
          archive(dir, arrival.file, 'rejected');
          continue;
        }
        const reply = e.replyTo === null ? '' : `, in reply to ${e.replyTo}`;
        // Journal first, archive second: a crash in between repeats the message rather than losing it.
        emit({ source: `agent:${e.from}`, text: `(message ${e.id}${reply}) ${e.text}` });
        archive(dir, arrival.file, 'seen');
      }
    };
    poll();
    const timer = setInterval(poll, intervalMs);
    return () => clearInterval(timer);
  };
}
```

```ts
import { existsSync, readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import type { JournalEvent } from '../kernel/journal';
import type { Stimulus } from './sensors';

/** Characters of soul shown per turn. The files themselves may be longer. */
export const SOUL_CAP = 20_000;

/** Every `.md` file in the soul directory, in name order, each under its file name. */
export function loadSoul(dir: string): string {
  if (!existsSync(dir)) return '';
  return readdirSync(dir)
    .filter((name) => name.endsWith('.md'))
    .sort()
    .map((name) => `### ${name}\n\n${readFileSync(join(dir, name), 'utf8').trim()}`)
    .join('\n\n');
}

/** The species' prompt, then the individual's soul. Built again every turn, since the soul can change. */
export function composeSystem(prompt: string, soulDir: string): string {
  const head = `${prompt.trim()}\n\n## Who you are\n\nYour soul directory is ${soulDir}.`;
  const soul = loadSoul(soulDir);
  if (soul === '') return `${head} It is empty: you have not been born yet. Your first message tells you what to do.`;
  const shown = soul.length <= SOUL_CAP
    ? soul
    : `${soul.slice(0, SOUL_CAP)}\n[your soul is longer than ${SOUL_CAP} characters; the rest is not shown. Shorten it.]`;
  return `${head} These files are yours. This is what they say now.\n\n${shown}`;
}

/** The birth letter, if this journal has never held a stimulus. */
export function birth(events: JournalEvent[], letter: string): Stimulus | null {
  return events.some((e) => e.type === 'stimulus') ? null : { source: 'birth', text: letter.trim() };
}
```

**Step 2: Write `body/main.ts`**

```ts
import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { appendEvent, readEvents } from '../kernel/journal';
import { needsTurn } from './context';
import { runTurn } from './loop';
import { openAiProvider } from './provider';
import { clock, inbox, terminal, type Sensor, type Stimulus } from './sensors';
import { birth, composeSystem } from './soul';
import { TOOLS, type ToolContext } from './tools';

function env(name: string): string {
  const value = process.env[name];
  if (!value) {
    console.error(`${name} is not set`);
    process.exit(1);
  }
  return value;
}

const gen = env('TENERAL_GEN');
const journal = env('TENERAL_JOURNAL');
const workspace = env('TENERAL_WORKSPACE');
const provider = openAiProvider({ baseUrl: env('TENERAL_BASE_URL'), apiKey: env('TENERAL_API_KEY'), model: env('TENERAL_MODEL') });
const heartbeatMinutes = Number(process.env.TENERAL_HEARTBEAT_MINUTES ?? '30');
const prompt = readFileSync(join(import.meta.dir, 'prompt.md'), 'utf8');
const letter = readFileSync(join(import.meta.dir, '..', 'BIRTH.md'), 'utf8');
const soulDir = env('TENERAL_SOUL');
const inboxDir = env('TENERAL_INBOX');
const ctx: ToolContext = { workspace, journal, gen, moltCommit: null, id: env('TENERAL_ID'), inbox: inboxDir, peers: env('TENERAL_PEERS') };

let quitting = false;
let wake: (() => void) | null = null;

// A stimulus is on disk before anything reacts to it, so a crash right after cannot lose it.
function emit(s: Stimulus): void {
  appendEvent(journal, gen, { type: 'stimulus', source: s.source, text: s.text });
  wake?.();
}

const sensors: Sensor[] = [
  terminal(console, () => { quitting = true; wake?.(); }),
  clock(heartbeatMinutes * 60_000),
  inbox(inboxDir),
];

/** One turn. False when it failed, so the caller waits for the next stimulus instead of spinning. */
async function turn(): Promise<boolean> {
  try {
    // The soul is read again each turn: the agent may have just rewritten it.
    const system = composeSystem(prompt, soulDir);
    const outcome = await runTurn({ journal, gen, provider, tools: TOOLS, system, ctx, onText: (t) => console.log(`\n${t}\n`) });
    if (outcome === 'molt') process.exit(75);
    return true;
  } catch (err) {
    console.error(`[turn failed] ${err instanceof Error ? err.message : String(err)}`);
    return false;
  }
}

// Everything above loaded and parsed: this generation can start.
appendEvent(journal, gen, { type: 'generation.ready', commit: gen });
// A journal with no stimulus yet means this individual was never born: the letter goes first.
const firstWords = birth(readEvents(journal), letter);
if (firstWords !== null) emit(firstWords);
const stops = sensors.map((start) => start(emit));

for (;;) {
  // Also true right after a restart: an unfinished turn or a kernel note is picked up here.
  while (!quitting && needsTurn(readEvents(journal))) {
    if (!(await turn())) break;
  }
  if (quitting) break;
  process.stdout.write('> ');
  await new Promise<void>((resolve) => { wake = resolve; });
  wake = null;
}

for (const stop of stops) stop();
process.exit(0);
```

### Task 16: Container

The body has a shell with the privileges of whoever runs it. On a bare machine that is the owner's whole account: their other projects, their SSH keys, their browser profile. So an individual is raised in a container that can see this repository and nothing else.

What this task gives, and what it does not:

- **It protects the machine from the agent.** Inside the container the only writable place is the repo directory; there is no home directory, no keys, no other project, no added privileges.
- **It does not protect the kernel from the body.** Both run in the same container as the same user, so the body can still edit `kernel/`, the state file and the journal directly. The gates remain a guard against mistakes, not against intent. Making the kernel a real boundary means running the body as a different user that cannot write the kernel's files, with the candidate as a separate clone rather than a worktree of the kernel's repository (a shared `.git` lets the body plant hooks and config the kernel's git would run). That is the next plan, not this one.
- **The network is open.** The agent needs to reach its model endpoint. Anything it can read (this repo and its own API key) it could also send somewhere.

One rule follows from how git worktrees work: they record absolute paths. An individual born in the container at `/teneral` must always be run there. Do not start the same checkout once on the host and once in the container.

**Files:**
- Create: `Dockerfile`, `.dockerignore`, `box`
- Modify: `package.json` (add a `box` script), `README.md`

All of these are outside `body/`, so the agent cannot change its own cage by molting.
